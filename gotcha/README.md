# "HAHA You thought" pictures

Drop image files in this folder (`.jpg`, `.png`, `.webp`, `.gif`; **not** iPhone `.heic`). The pictures are shown around the
password box on the Ring & Proposal page (shuffled each visit). With no pictures here it shows
just the box.

**Size tips:** about 1000–1400 px on the longest side, JPEG quality ~80, ideally under 400 KB each.
Phone photos are usually 3–5 MB, so shrink them first or they will load slowly.
